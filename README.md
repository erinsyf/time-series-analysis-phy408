# Computational Data Analysis — PHY408

Selected original Jupyter notebook exercises from PHY408 at the University of Toronto, covering sampling, convolution, spectral analysis, physical data modelling, and digital filtering.

## Notebooks

### Signal processing
- `signal-processing/lab1_q3.ipynb` — Sampling and aliasing
- `signal-processing/lab2_q1.ipynb` — Discrete convolution
- `signal-processing/lab2_q2.ipynb` — Seismic signal convolution and smoothing
- `signal-processing/lab3_q3.ipynb` — Wave signal Fourier analysis and reconstruction

### Physical data analysis
- `physical-data-analysis/lab3_q4.ipynb` — Argon radial distribution analysis

### Digital filters
- `digital-filters/lab4_q1.ipynb` — Digital notch filter
- `digital-filters/lab4_q2.ipynb` — Filtering atmospheric methane time series

## Requirements

Python with Jupyter, NumPy, SciPy, Matplotlib and pandas. 

## Data File Availability

Some notebooks use datasets supplied as part of PHY408 coursework at the University of Toronto.

The original code, analysis, and saved outputs are preserved, but certain input datasets are not redistributed.

- **Atmospheric methane:** Publicly available data can be obtained from [NOAA Global Monitoring Laboratory](https://gml.noaa.gov/ccgg/trends_ch4/). Note that the original course dataset may be different.
- **Seismic signal:** The course-provided synthetic seismogram (`RAYN.II.LHZ.sem`) is not included.
- **Wave signals:** The original signal datasets were provided by the course instructor and are not included.

Notebooks requiring unavailable datasets can be viewed with their saved outputs, but cannot be rerun without changing input files.

These projects are shared to document the numerical methods and scientific analysis completed during PHY408.
